# Install your GitHub profile

1. On GitHub, create a new **public** repository named exactly `katenoahpersonal-svg`.
2. Check **Add a README file** when creating it.
3. Open the new repository and choose **Add file → Upload files**.
4. Upload this kit's `README.md` and the entire `assets` folder. If GitHub asks, replace the starter README.
5. Commit the files to the `main` branch.
6. Return to `https://github.com/katenoahpersonal-svg` and refresh. The custom profile will appear above your pinned repositories.

## Before publishing

- Open each featured-project link and confirm the capitalization matches the repository URL.
- Replace any project description that no longer reflects the work.
- If one of the external activity images ever stops loading, remove only that `<img>` line; the rest of the profile remains intact.

## Optional polish inside GitHub

- Pin your four strongest repositories in the same order used in the README.
- Add a one-sentence description and a social preview image to every featured repository.
- Add a short profile bio such as: `Creative technologist crafting digital worlds through design, code & film.`
